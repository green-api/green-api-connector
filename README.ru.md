# GREEN-API Connector

> **English Version**  
> The English version of README is available at [`README.md`](README.md)  

Расширение помогает получить данные для авторизации WhatsApp инстанса, когда нет возможности совершить авторизацию через стандартные способы. Например, когда вход возможен только через технологию Passkey. 

## Как работает расширение?

Расширение открывает отдельное окно WhatsApp Web для прохождения авторизации, после чего отправляет данные на заданный в [запросе](#исходящие-запросы) endpoint. 

## Сборка
1. Установить зависимости 
    ```bash
    npm install 
    ```
2. Собрать расширение
    * Chrome:
      ```bash
      npm run build
      ```
    * Firefox:
      ```bash
      npm run build:firefox
      ```
3. Распакованное расширение для бразуера будет в папке `dist/`

## Быстрый старт

Проверить как работает расширение можно через тестовую страницу [`example/index.html`](example/index.html).  
Для локальной проверки через localhost сервер или через открытый файл необходимо собрать расширение с включенным флагом `DEV_MODE` из [config.ts](src/shared/config.ts).

## Как работать с расширением

Передача данных между страницей и расширением происходит через [события `message`](https://developer.mozilla.org/en-US/docs/Web/API/Window/message_event).

### Исходящие запросы 

Пример payload запроса: 
```json
{"target": "green-api-connector", "type": "PING"}
```
* `target` - маркер расширения. Указывается в [config.ts](src/shared/config.ts) через переменную `CONNECTOR_SOURCE`
* `type` - тип исходящего запроса

Возможные значения поля `type`:
* `PING` - проверка что расширение установлено и доступно на странице
* `START_PASSKEY_IMPORT` - запустить процесс авторизации. Необходимо добавить URL endpoint в поле `url` куда будут отправлены [данные авторизации](#как-использовать-данные-авторизации) 
* `CLEAR_AND_CONTINUE` - очистить данные, если они существуют и запустить процесс авторизации. Можно использовать если был получен [ответ](#входящие-запросы) с типом `EXISTING_SESSION`, чтобы принудительно начать процесс авторизации
* `CANCEL_IMPORT` - отменить процесс авторизации. Если ранее было открыто окно с Web версией, оно будет закрыто

Пример запроса в коде:
```js
window.postMessage({target:"green-api-connector", type:"START_PASSKEY_IMPORT", url:"https://example.com"}, '*')
```

### Входящие запросы

Для получения событий необходимо подписаться на события `message`. 

Чтобы обрабатывать только события от расширения можно реализовать фильтр по маркеру расширения, например:
```js
window.addEventListener('message', (event) => {
  if (event.source !== window || event.data?.source !== 'green-api-connector') {
    return 
  }
  // логика обработки события от расширения
})
```

Пример payload входящего запроса:
```json
{"source":"green-api-connector","type":"CONNECTOR_READY"}
```
* `source` - маркер расширения
* `type` - тип ответа

Возможные значения поля `type`:
* `CONNECTOR_READY` - ответ на PING. Также отправляется при успешной активации на странице
* `IMPORT_SENT` - успешная отправка данных на указанный в `url` endpoint. Имеет дополнительные поля `name` и `number`. 
* `EXISTING_SESSION` - уже есть вход в аккаунт. Данные не были отправлены на endpoint
* `IMPORT_ERROR` - ошибка в процессе синхронизации. Причина указана в дополнительном поле `reason`:
  * `import_already_in_progress` - процесс авторизации уже запущен
  * `tab_closed` - вкладка для авторизации была закрыта до завершения авторизации
  * `unexpected_error` - произошла непредвиденная ошибка во время процесса авторизации

## Как использовать данные авторизации

Для авторизации на инстансе необходимо при запросе `START_PASSKEY_IMPORT` указать url в формате: 
```
https://api.green-api.com/waInstance{{idInstance}}/setAuthCreds/{{apiTokenInstance}}
```
* `{{idInstance}}` - номер инстанса из личного кабинета
* `{{apiTokenInstance}}` - токен инстанса из личного кабинета

Например:
```js
window.postMessage({target:"green-api-connector", type:"START_PASSKEY_IMPORT", url:"https://api.green-api.com/waInstance110501234567/setAuthCreds/Jg9ktxJ5d7pfWVT9Whar9qxmVVPMLN4d49C8nmpbjXyNeYq54b"}, '*')
```

При использовании своего backend сервера необходимо проксировать данные полученные от расширения на нужный инстанс.

## Как кастомизировать расширение

### Конфигурация
Настроить конфигурацию расширения можно через файл [`src/shared/config.ts`](src/shared/config.ts)
* `CONNECTOR_SOURCE` - маркер используемый при отправке запросов и фильтрации входящих запросов 
* `TRUSTED_DOMAINS` - домены на которых расширение будет активно. Например при указании `green-api.com` расширение будет активно и на странице `console.green-api.com`.
* `DEV_MODE` - позволяет работать расширению на `http://localhost` и из открытого в браузере HTML файла. Рекомендуется выключить при публикации расширения

### Изображения
Для использования своего логотипа необходимо заменить файлы из папки `public/icons`

### Текст
Текст заголовка и описания в меню расширения отображается на основе данных из папки `public/_locales`

### Цвета
Палитру цветов можно поменять через CSS файл [src/shared/theme.css](src/shared/theme.css)
