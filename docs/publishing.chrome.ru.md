# Публикация расширения в Chrome Web Store

[English version](publishing.chrome.md)

Инструкция публикации расширения GREEN-API Connector или его white label версии в Chrome Web Store.

## Требования для публикации в Chrome Web Store

**Аккаунт** - Google-аккаунт (брендовый аккаунт вашей компании) → [Developer Dashboard](https://chrome.google.com/webstore/devconsole)  
**Взнос** - Разовый взнос для публикации расширения (около 5 USD)  
**Что загружать** - архив `release/<name>-<version>-chrome.zip`  
**Проверка** - Обычно несколько дней, иногда до нескольких недель

## Шаг 1. Собрать релиз

В магазин загружается только ZIP-файл из корня папки релиза.

1. Соберите релиз в корне репозитория:
   - Воспользуйтесь конструктором из инструкции [«Быстрый старт»](../README.ru.md#быстрый-старт)
   - Или соберите релиз командой: `npm run release -- --lang ru` (ваш бренд из `branding/`)
     или `npm run release -- --lang ru --default-brand` (стандартный GREEN-API Connector)
2. Откройте `release/<name>-<version>/` и возьмите `<name>-<version>-chrome.zip`.
3. Для обновления уже опубликованного расширения сначала поднимите версию: `npm version patch --no-git-tag-version`,
   затем соберите заново. Магазин не примет ту же версию повторно.

Перед загрузкой проверьте:

- Расширение из `chrome/` проверьте вручную в браузере, [установите расширение локально](./install.browser.ru.md).
- Название и иконки — вашего бренда (магазин отклоняет чужое или похожее на чужое оформление).

## Шаг 2. Опубликовать в Chrome Web Store

Загрузите `-chrome.zip`, заполните вкладки продукта и отправьте на проверку. Для B2B-инструмента обычно подходит
видимость Unlisted: расширение доступно только по ссылке.

1. Зарегистрируйтесь в [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) под
   Google-аккаунтом компании и оплатите разовый взнос ([Зарегистрируйте свою учетную запись разработчика](https://developer.chrome.com/docs/webstore/register)).
   Email для связи потом не меняется — выберите общий адрес, а не личный
   ([Настройте свою учетную запись разработчика](https://developer.chrome.com/docs/webstore/set-up-account)).
2. В личном кабинете разработчика выберите **Продукты** → **Добавить продукт** → **Выбрать файл** `release/<name>-<version>-chrome.zip` → **Загрузить**.  
   [Публикация в Интернет-магазине Chrome](https://developer.chrome.com/docs/webstore/publish)
3. Перейдите в загруженный продукт и заполните **Описание продукта** для каждого из языков, рекомендуемое описание:

   **Сведения о продукте**

   Внимание! Скорректируйте текст для вашей компании

   ```
   <Ваше наименование приложения> позволяет подключить аккаунт WhatsApp к сервису <Наименование вашего сервиса>.

   По запросу пользователя расширение получает данные текущей авторизованной сессии WhatsApp Web и безопасно передает их в аккаунт <Наименование вашего сервиса>. После успешного переноса локальная сессия WhatsApp Web закрывается.

   Расширение работает только с сайтом WhatsApp Web и выполняет импорт исключительно после явного действия пользователя. Полученные данные используются только для подключения аккаунта к <Наименование вашего сервиса> и обеспечения работы сервиса.
   ```

   **Категория**  
   Инструменты

   **Графические объекты**  
   [Предоставление изображений](https://developer.chrome.com/docs/webstore/images).  
   Значок 128×128 пикселей можно взять из папки с релизом `release/<name>-<version>/chrome/icons/icon128.png`

   **Глобальные скриншоты**  
   Тут требуются:
   - Изображение вашего сайта с изображением работающего расширения
   - Изображение WhatsApp Web с прохождением авторизации через Passkey

   **Дополнительные поля**  
   Укажите ссылки на официальный сайт вашего сервиса

4. Перейдите в пункт **Конфиденциальность**  
   [Заполните поля конфиденциальности](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy).

   Рекомендация по заполнению полей:

   **Единственное назначение**

   ```
   Выполняем код на странице WhatsApp Web для получения данных авторизованной сессии, необходимых для импорта аккаунта в <Название вашего продукта>.
   ```

   **Обоснование для использования разрешения**

   ```
   Раздел scripting
   Выполняем код на странице WhatsApp Web для получения данных авторизованной сессии, необходимых для импорта аккаунта в <Название вашего продукта>.

   Раздел tabs
   Создаем, активируем и закрываем вкладку WhatsApp Web, необходимую для выполнения импорта авторизованной сессии.

   Раздел browsingData
   Очищаем локальные данные WhatsApp Web после завершения импорта для предотвращения конфликтов между локальной веб-сессией и подключенной сессией <Название вашего продукта>.

   Раздел разрешения на доступ к хостам
   Доступ требуется исключительно к странице WhatsApp Web для получения данных авторизованной сессии пользователя по его запросу и выполнения процедуры импорта в <Название вашего продукта>. Расширение не взаимодействует с другими сайтами.
   ```

   **Передача данных**  
   Отметить пункты:
   - Данные для аутентификации
   - Личная коммуникация

   **Политика конфиденциальности**  
   Укажите ссылку на политику конфиденциальности вашего продукта

5. Перейдите в пункт **Распространение**

   **Платежи**  
   Бесплатно

   **Доступность**  
   Тут необходимо определить ссылку на доступ к расширению для ваших пользователей (по умолчанию Общедоступно)

   **Распространение**  
   Выберите требуемые для вас регионы

6. После заполнения всех форм на требуемых языках вы сможете нажать **Отправить на проверку**.  
   Если снять галочку автопубликации, после проверки у вас будет 30 дней, чтобы опубликовать вручную.

> Новый аккаунт разработчика сначала может опубликовать не больше двух расширений.

## После отправки

[Процесс проверки Интернет-магазина Chrome](https://developer.chrome.com/docs/webstore/review-process).

Результат проверки приходит на email аккаунта разработчика. Обычно проверка занимает несколько дней, иногда до нескольких недель.  
Новый аккаунт, новое расширение и разрешения вроде `browsingData` и доступа к сайтам удлиняют проверку.

Если прошло больше трёх недель, пишите в поддержку Google.

**Если отклонили.** Причина указана в письме и в кабинете. Чаще всего это обоснование разрешений, политика конфиденциальности, не совпадающая с формой, или описание. Исправьте, поднимите версию, соберите заново и отправьте снова.
